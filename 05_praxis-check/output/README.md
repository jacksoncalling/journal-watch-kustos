# Praxis-Check Dossiers (Produkt)

Generierte Dossiers landen hier, ein Markdown pro Frage. Vom Code geschrieben,
disponibel und reproduzierbar. Das Methoden-Repo committet Demo-Dossiers; echte
Dossiers leben im privaten Repo.

Neben jedem Dossier liegt `<name>.evidence.json`: was die Synthese tatsächlich
gesehen hat. Prüfen mit `python scripts/check_claims.py <dossier.md>`. Die drei
August-Dossiers haben eine nachträglich rekonstruierte Datei
(`"reconstructed": true`).
