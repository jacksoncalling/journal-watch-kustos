name: Evidence brief direction
description: User-approved presentation direction and pilot feedback about dossier length.
---

Show a short evidence brief first and keep the full dossier expandable. Preserve access to the bibliography.

**Why:** Pilot feedback was that the text is too long. The clinician already holds the clinical context and wants research to assess plausibility, then inspect deeper when needed. The user explicitly selected the short-brief-first direction.

**How to apply:** Use this direction when agreeing the next presentation and writing-contract changes. Do not treat the discussion's proposed word budget or backend implementation as separately approved requirements.

New app work must complement the existing folder-based operating and regulatory rules, rather than introduce a competing set of web-only instructions.

**Why:** The user explicitly asked to inspect the folder system, including EU AI Act requirements and how the software operates, and to write the rules there.

**How to apply:** Read the relevant source contracts before changing output behavior. Keep writing rules in the existing contract and interface documentation subordinate to it. Distinguish intended-purpose documentation from a verified legal compliance assessment.
