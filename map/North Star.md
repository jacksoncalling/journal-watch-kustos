# North Star

Kustos is a deterministic literature pipeline whose single point of judgment, one LLM synthesis call, is also its most load-bearing node: by betweenness, everything funnels through [[Synthesize]], wrapped in guardrails enforced in code precisely because it is the one stage that could fabricate. The engine is built, dense, and more honest than its own docs, reading the code overturns three "known issues" that are already fixed (the seed pin, the git repo, the committed feedback contract). For a developer asking "can this hold water in production", the pipeline can. The map's finding is that the risk has moved off the code and onto two seams. The human seam: the highest-betweenness ghost in the whole map is [[The Clinician]] the pipeline points at but no instantiation serves, with [[Feedback Stage]] (an unbuilt stage a human stands in for) close behind. The documentary seam: a single [[The Maintainer]] whose notes drift faster than the code ([[Documentation Drift]]). None of the gaps are bugs. All of them are marked. Walk the engine cluster to see what works; walk the surface cluster to see what is missing.
