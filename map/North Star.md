# North Star

Kustos is a deterministic literature pipeline whose one LLM synthesis call is wrapped in guardrails enforced in code, and whose Python core has not moved since the map was first drawn. The correction this rerun made is the important one: the served user is not a ghost. Real physicians use the published app now, so [[The Clinician]] is live. But all three share one login and one Dr. Demo cardiac-anaesthesia [[Profile]], so the consequential absence moved from the user to the personalization: [[Real Instantiation]], the per-physician real config the product exists to deliver, is referenced everywhere and built nowhere, and any user who is not a cardiac anaesthetist is being fed the wrong subspecialty. Two things worth holding apart: the graph's busiest ghost is [[Feedback Stage]] (a broker between memory and delivery), while the absence that matters most for the live product is Real Instantiation, structural centrality and product consequence are not the same measure, and here they point at different nouns. The busiest node overall is [[The Maintainer]]: bus-factor of one, whose notes drift faster than the code ([[Documentation Drift]]). The presentation gradient the map predicted has since been built by Replit. For a developer asking "can this hold water in production": the engine can, and it is live; what is missing is per-user identity and per-user literature, not more pipeline.
