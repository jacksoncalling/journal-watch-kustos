# Profile

The single source of configuration truth, as a Markdown file. Topics, trusted journals, provider choice, the ## Domain-Gate block, and max_dossiers_per_day all live here for the demo 'Dr. Demo'. The private instantiation would swap this one file for a real clinician's real topics. In ICM terms, the folder is the database and this is its main table.

read-by [[Rank]] . read-by [[Fetch]] . read-by [[Gate Layer]] . governed-by [[Folder is the Database]] . would-hold [[The Clinician]] real topics

- **Hits:** [[Rank]] scoring, [[Fetch]] queries, and the [[Gate Layer]]. Almost every stage reads it; a topic change ripples through the whole pipeline on the next run.
- **Does not hit:** [[Kanon]]. Profile is authored config (what to watch); Kanon is learned memory (what she liked). Both are read by Rank but they are different files with different lifecycles.
