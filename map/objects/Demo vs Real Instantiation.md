# Demo vs Real Instantiation

The build-out-loud pull, now sharper because it is live. The public method repo ships a fiction ('Dr. Demo', no real data) so it can be public and safe. The value only exists once each clinician's real subspecialty topics live in a private instantiation. The twist the deployment reveals: the demo is not a placeholder waiting for the real thing, it IS the production config. Real physicians use the published app on Dr. Demo's cardiac profile. So both sides are live at once, the public demo and the real users, fused into one running instance, and the [[Real Instantiation]] that would separate them is still absent.
