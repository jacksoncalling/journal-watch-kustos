# Demo vs Real Instantiation

The build-out-loud pull. The public method repo must ship a fiction ('Dr. Demo', no real data) so it can be public and safe. But the value only exists once a real clinician's real, sensitive subspecialty topics live in a private instantiation, which does not exist yet. Both sides live: publishing the method openly and serving a real user pull in opposite directions, and the second has not happened.
